# yt-agentic

Agentic AI control system that produces videos for up to 20 YouTube channels with a mandatory
human approval gate. See `CLAUDE.md` for invariants and commands, `docs/adr/` for decisions and
`docs/threat-model.md` for the threat model.

```bash
make setup      # create .venv, install deps, install pre-commit hooks
make up         # local Postgres (pgvector) + Temporal
make test-all   # lint, typecheck, generated-file and migration checks, tests, DB guard tests
```

## Deployment target (Phase 4)

Chosen target: **Google Cloud** (Terraform in `infra/terraform`, one root module per
environment: `envs/staging`, `envs/production`).

| Concern | Resource | Notes |
|---|---|---|
| Postgres + pgvector | Cloud SQL (Postgres 16), private IP, PITR | regional HA in both envs |
| Object storage | GCS bucket, versioned, public access prevented | content-addressed keys under `channels/<id>/` |
| Backups | separate GCS bucket (multi-region), versioned, retention policy | daily logical dump + restore drill |
| Secrets | Secret Manager (containers only; values added out of band) | signing key readable by the hub only |
| Containers | Cloud Run services (hub, gateway, metrics exporter), internal ingress | one service account each |
| Rendering workers | Cloud Run **worker pool** `render-worker-<env>` | pull-based Temporal workers, scaled by hand |
| Scheduled jobs | Cloud Run jobs + Cloud Scheduler: planner (hourly), monitor, breaker, analytics, backup | all idempotent |
| Orchestrator | **Temporal** (Temporal Cloud or self-hosted); address is a variable | namespaces `ytcore-staging` / `ytcore-prod` |
| Observability | OpenTelemetry traces (one trace per job), Prometheus metrics, Grafana dashboard + alert rules generated by `ytcore/observability/dashboards.py`; Cloud Monitoring policies for infra | |

The Python side is provider-neutral: storage, secrets, queue and YouTube are behind small
interfaces (`ListableAssets`, `SecretsProvider`, `YouTubeClient`); moving clouds means a new
Terraform root plus adapters for those interfaces.

Entry points: `python -m ytcore.workflow.worker run|plan-once`,
`python -m ytcore.observability.monitor check`, `python -m ytcore.safety.breaker run-once`,
`python -m ytcore.analytics.ingest run-daily`, `python -m ytcore.ops.backup backup|restore-drill`.
Runbooks: `docs/runbooks/`.
